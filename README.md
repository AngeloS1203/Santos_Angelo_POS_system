# POS System

## IT0049 - Web System Technologies

This project is a basic Point-of-Sale (POS) system developed using CodeIgniter 4.

## Pages

The system contains four pages:

- Home
- About
- Customer Accounts
- User Accounts

## Routes

- `/` - Home
- `/about` - About
- `/customers` - Customer Accounts
- `/users` - User Accounts

## Customer Accounts

The Customer Accounts page contains five customer records with:

- Full Name
- Email
- Phone Number

The records are stored using a static PHP array and displayed using a `foreach` loop.

## User Accounts

The User Accounts page contains five user records with:

- Username
- Full Name
- Role

The records are stored using a static PHP array and displayed using a `foreach` loop.

## Requirements

- PHP 8.2 or higher
- Composer
- CodeIgniter 4
- Web Browser
